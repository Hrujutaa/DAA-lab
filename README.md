This repository contains implementations of fundamental algorithms studied in the Design and Analysis of Algorithms course. The programs focus on problem-solving techniques including divide and conquer, greedy algorithms, dynamic programming, backtracking, graph algorithms, and recursion.

All implementations are written in a standard programming language (C/C++/Python as applicable) and demonstrate algorithmic efficiency and complexity analysis.



Overview

This repository includes implementations of:

* Graph algorithms
* Sorting algorithms
* Searching algorithms
* Greedy techniques
* Dynamic programming
* Backtracking problems
* Recursive algorithms

The objective of this repository is to understand algorithm design strategies and analyze time and space complexity.


Algorithms Implemented

1. Graph Algorithms

Dijkstra’s Shortest Path Algorithm

* Single-source shortest path algorithm
* Uses greedy strategy
* Time Complexity: O(V^2) or O(E log V) with priority queue

Floyd-Warshall Algorithm

* All-pairs shortest path algorithm
* Based on dynamic programming
* Time Complexity: O(V^3)

Kruskal’s Algorithm

* Minimum Spanning Tree (MST)
* Uses greedy approach and disjoint set (Union-Find)
* Time Complexity: O(E log E)

Prim’s Algorithm

* Minimum Spanning Tree (MST)
* Greedy technique
* Time Complexity: O(V^2) or O(E log V)


2. Sorting Algorithms

Merge Sort

* Divide and Conquer algorithm
* Stable sorting algorithm
* Time Complexity: O(n log n)

Quick Sort

* Divide and Conquer algorithm
* In-place sorting
* Average Time Complexity: O(n log n)
* Worst Case: O(n^2)



3. Searching Algorithms

Binary Search using Recursion

* Works on sorted arrays
* Time Complexity: O(log n)

Linear Search using Recursion

* Sequential search technique
* Time Complexity: O(n)


4. Greedy Algorithms

Fractional Knapsack

* Items can be divided
* Maximizes profit based on value/weight ratio
* Time Complexity: O(n log n)

Knapsack Problem (0/1 Knapsack)

* Dynamic programming approach
* Items cannot be divided
* Time Complexity: O(nW)

Optimal Merge Pattern

* Minimizes total merging cost
* Greedy strategy using priority queue



5. Backtracking

N-Queens Problem

* Places N queens on an N×N chessboard
* Ensures no two queens attack each other
* Solved using backtracking
